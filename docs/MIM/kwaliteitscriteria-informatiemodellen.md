# Kwaliteitscriteria voor informatiemodellen

**Regel:** Informatiemodellen in UML maken gebruik van het MIM 1.2 Metamodel

**Regel:** In een model wordt duidelijk onderscheiden of het een conceptueel- of een logisch model is.

**Regel:** Klassen in een conceptueel model verwijzen naar bovenliggende begrippen in een begrippencatalogus.

**Regel:** Informatiemodellen worden vastgelegd in een ReSpec document.

**Regel:** Informatiemodellen maken uitsluiten gebruik van datatypen in MIM-Datatypen of ISO19107-Datatypen.
