# Beheer GitHub

## Github beheer

Github beheerders zijn te vinden in het github [gebuikersoverzicht](https://github.com/orgs/Geonovum/people?query=role%3Aowner).

**Regel:** Alle teamleden hebben 2FA aanstaan. (Vanuit Github required voor contributors) [Configure 2FA](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication)

**Regel:** De beheerders van GitHub bepalen wie onderdeel is van de Geonovum organisatie. In principe loopt dat gelijk met het hebben van een Geonovum email
account. Hierop zijn uitzondering mogelijk die we bijhouden via pas-toe-of-leg-uit.

**Regel:** Wie behoort tot de Geonovum organisatie heeft toegang tot GitHub repositories via GitHub teams.

**Regel:** Mensen buiten de Geonovum organisatie kunnen individueel toegang krijgen tot repositories. Hierdoor worden ze [outside collaborator](https://docs.github.com/en/organizations/managing-user-access-to-your-organizations-repositories/managing-outside-collaborators/adding-outside-collaborators-to-repositories-in-your-organization#about-outside-collaborators). Per outside collaborator is te zien tot welke repositories ze toegang hebben via [deze link](https://github.com/orgs/Geonovum/outside-collaborators) (als admin).

**Noot:** Er is geen bezwaar tegen het gebruik van een privé github account binnen het Geonovum team. Achterliggende gedacht is dat er flink wat mensen al een github account hebben en het geen toegevoegde waarde heeft om een tweede github account te hebben.

## GitHub teams

Er is een aantal teams gemaakt binnen Geonovum. Deze zijn te vinden op: <https://github.com/orgs/Geonovum/teams>.

**Regel:** Ieder team is gekoppeld aan een actief project binnen Geonovum.

**Regel:** Repositories met content die in beheer zijn horen bij een team dat aanspreekpunt is voor die repository. Andere repositories geven in de README.md aan wie aanspreekpunt is voor die repository.

**Conventie:** Team namen eindigen op ' team'. Bijvoorbeeld 'DSO team'.
